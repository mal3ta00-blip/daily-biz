# DAILY BIZ — النسخة التجريبية

هذه نسخة أولية ثابتة (Static) من DAILY BIZ.

## التشغيل على الكمبيوتر
1. فك ضغط الملف.
2. افتح `index.html` باستخدام Chrome أو Edge.

## النشر المجاني عبر GitHub Pages
1. أنشئ حساباً في GitHub إذا لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً باسم `daily-biz`.
3. ارفع ملف `index.html` إلى جذر المستودع.
4. افتح Settings ثم Pages.
5. اختر النشر من فرع `main` ومجلد `/root`، ثم احفظ.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## حدود هذه النسخة
- البيانات محفوظة محلياً داخل المتصفح فقط.
- لا توجد حسابات مستخدمين أو مزامنة بين الأجهزة.
- لا توجد بوابة دفع أو اشتراكات فعلية.
- لا تستخدم هذه النسخة لحفظ بيانات حساسة أو بيانات دفع.
- ليست نظام فواتير ضريبية إلكترونية معتمداً.

قبل استقبال عملاء مدفوعين، يجب إضافة خادم وقاعدة بيانات ومصادقة آمنة،
وسياسة خصوصية وشروط استخدام، ثم ربط بوابة دفع مناسبة والتحقق من المتطلبات النظامية في السعودية.
